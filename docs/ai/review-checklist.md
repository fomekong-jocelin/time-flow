# Review checklist — TimeFlow

- [ ] Le besoin et les critères d'acceptation sont couverts.
- [ ] Pas de logique métier dans controller/composant UI.
- [ ] Contrats API explicites et versionnés.
- [ ] Validation des entrées présente.
- [ ] Autorisation deny-by-default vérifiée.
- [ ] Aucun secret ou donnée sensible dans code/logs.
- [ ] Migration DB versionnée si schéma modifié.
- [ ] Tests ajoutés ou mis à jour.
- [ ] UX responsive et accessible si UI modifiée.
- [ ] `PROJECT-TRACKING.md` et `CHANGELOG.md` à jour.
- [ ] Risques et reste à faire explicités dans le ticket.
